Panduan VirtualBox & Debian

Dari unduh sampai siap instal, langkah demi langkah.

1. Download VirtualBox

  1. Buka situs resmi VirtualBox, lalu masuk ke halaman Downloads.
  2. Pilih paket sesuai sistem operasimu, misalnya Windows hosts (tersedia juga untuk macOS dan Linux).
  3. Jalankan installer, klik Next sampai selesai, lalu Finish. Koneksi internet bisa terputus sebentar saat instalasi.
  4. Kalau nanti VM gagal menyala, aktifkan virtualisasi (VT-x / AMD-V) di BIOS.
BUKA SITUS VIRTUALBOX

2. Download ISO Debian

  1. Buka halaman unduhan Debian dan cari bagian netinst.
  2. Pilih arsitektur amd64 untuk PC atau laptop 64-bit. Ukuran file kecil, tapi butuh internet saat instalasi.
  3. Simpan file berekstensi .iso di folder yang mudah kamu ingat.
  4. Opsional: cocokkan checksum dengan file SHA256SUMS untuk memastikan file tidak rusak.
BUKA SITUS DEBIAN

3. Buat Mesin Virtual

  1. Di VirtualBox klik New, isi nama (misalnya Debian), pilih file ISO tadi, Type Linux, Version Debian (64-bit).
  2. Atur RAM minimal 2048 MB dan CPU 2 core.
  3. Buat hard disk virtual sekitar 20 GB.
  4. Klik Start, pilih Graphical install, lalu ikuti wizard sampai selesai.
  Setelah instalasi selesai, lepas ISO dari virtual optical drive supaya VM boot dari disk.

Materi 2

Pengertian Debian

Debian adalah sistem operasi berbasis Linux yang bersifat open source dan banyak digunakan sebagai sistem operasi server.

Debian dikembangkan oleh komunitas relawan sejak 1993, terkenal stabil, dan memakai paket .deb yang dipasang lewat apt. Di praktikum ini kita memakai Debian 13 "Trixie" 64-bit.

Materi 3

Pengertian Direktori

Direktori adalah tempat atau wadah untuk menyimpan dan mengorganisasi file maupun direktori lainnya. Di Windows kita menyebutnya folder.

Contoh dari praktikum: folder tugas_asj di dalam /home/axioo.

Linux memakai struktur pohon dengan satu akar / (root), tidak ada drive C: atau D:.

Materi 4

Cara Download VirtualBox

  1. Masuk ke Google / Chrome.
  2. Cari VirtualBox.
  3. Klik pilihan Download.
  4. Gulir, cari pilihan Windows hosts.
  5. Download filenya.
  6. Buka file manager, cari file yang tadi diunduh.
  7. Install, tinggal klik Next sampai selesai.

Materi 5

Cara Download Debian

  1. Cari Debian di Google / Chrome.
  2. Klik hasil paling atas.
  3. Gulir sampai ada tulisan Download.
  4. Klik Download.

ISO yang dipakai di praktikum: debian-13.7.0-amd64-netinst.iso (Debian 13 Trixie, 64-bit).

Materi 6

Cara Install Debian

  1. Buka VirtualBox, lalu klik New.
  2. Beri nama, lalu pilih file .iso Debian tadi.
  3. Pilih OS Linux, distribusi Debian.
  4. Klik Next.
  5. Sesuaikan Base Memory, CPU, dan Disk Size.
  6. Ikuti instruksi installer hingga selesai (hostname, partisi, user).
Tampilan tiap langkah ada di Dokumentasi di bawah.

Materi 8

Hak Akses & chmod

Permission menentukan siapa yang boleh membuka, mengubah, atau menjalankan file/direktori. Linux membaginya ke tiga kelompok: u (User/Owner), g (Group), dan o (Others).

Read (r) = 4
membaca isi file atau melihat daftar isi direktori
Write (w) = 2
mengubah isi file; pada direktori, mengelola entri di dalamnya
Execute (x) = 1
menjalankan file, atau menelusuri/mengakses direktori

Tanda - berarti izin tidak diberikan. Angka permission dijumlahkan per kelompok: rwx = 7, rw- = 6, r-x = 5, r-- = 4.

Praktik langkah demi langkah
  1. Buat file: touch file.txt
  2. Lihat permission: ls -l file.txt
  3. Ubah permission: chmod 761 file.txt
  4. Periksa lagi: ls -l file.txt
Hasil percobaan di terminal
644 → -rw-r--r--744 → -rwxr--r--764 → -rwxrw-r--761 → -rwxrw---x

Cara Pembuatan Hak Akses pada Debian

Sesuai materi Kelompok Bayu, perintah chmod 761 file.txt membagi izin kepada 3 kategori pengguna:

7
Pemilik (Owner) — rwx

Bisa membuka (x), membaca (r), dan menulis (w) file.

4 + 2 + 1
6
Grup (Group) — rw-

Bisa membaca (r) dan menulis (w) file.

4 + 2 + 0
1
Pengguna Lain (Others) — --x

Hanya bisa membuka / menjalankan (x) file.

0 + 0 + 1
Read (r)
Izin membaca isi file.
Write (w)
Izin mengubah/menulis file.
Execute (x)
Izin menjalankan file/folder.
root@debian-kelompok-bayu: ~
# Klik tombol langkah di bawah untuk menjalankan praktik Debian:
root@debian:~# mkdir praktikum_bayu && cd praktikum_bayu

Kesimpulan Praktikum

VirtualBox merupakan perangkat lunak yang memungkinkan kita menjalankan sistem operasi lain secara virtual tanpa harus mengganti sistem operasi utama pada komputer. Dengan VirtualBox, Debian dapat diinstal dan digunakan sebagai sistem operasi virtual untuk melakukan berbagai praktik.

Debian merupakan sistem operasi berbasis Linux yang memiliki struktur file dan direktori yang terorganisasi. Dalam Debian, direktori digunakan sebagai tempat untuk menyimpan dan mengatur file maupun direktori lainnya.
